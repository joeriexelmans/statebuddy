Tutorial 0 - What is statebuddy & why was it created?
----------



Motivation:
	- alternative to Yakindu / Itemis
		- simpler visual editor
			- doesn't try to 'help' you, no heuristics, no fancy layout algorithms
			- no hidden information
		- inspect execution traces + microsteps
		- rollback execution steps
		- better testing framework
		- web-based (no intallation)
		- integrated solution for teaching (exercises)

Lacking features:
	- no code generation (e.g., C/C++)
	- side effects currently only via MQTT
