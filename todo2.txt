Desirable features
------------------

- need some way of persisting recorded traces in localstorage
    possible approach:
      mapping app-state-hash -> recording
      use 'reference counting' (count number of browser windows that have the app-state-hash open)
      if refcount == 0, AND the app-state-hash hasn't been opened in 30 days, THEN delete the recording.
    benefits:
      - bookmarking remains the main save-mechanism.
      - Ctrl+S for export if you wanna be sure not to lose your recording.

- support 'default history' (syntax already allows it, semantics ignore it)

- store user actions:
    motivation
      1. make history explainable
      2. history uses less memory

- fork/join for synchronization of orthogonal regions
