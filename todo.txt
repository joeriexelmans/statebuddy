Language features
    abstract syntax
        - and/or states
        - pseudo-states
        - enter/exit trigger
        - shallow/deep history
        - transitions
            - event/after trigger
            - event parameters
            - guard expressions
        - action language
            expressions:
                - arithmetic, logic
                - variable references
                - function calls
            actions:
                - variable assignment
                - raising output events
    semantics
        - omniscient debugging
        - recording and replaying traces
        - time:
            - paused / step-wise
            - (scaled) real time
        - interactively raising input events
        - coupled execution with "plant"
            - 3 hardcoded plants
        - MTL property checking

Editor features
    - select/move/resize
        Shift key to grow selection
    - copy/paste
    - rotate
    - find & replace

App features
    - light/dark mode

Performance
    - spatial hashing to speed up 'connectness' and 'insideness' detection
    - very fast loading (especially compared to yakindu...)
