1. Microwave Adventure

1.1 Introduction

You are hired by PARASONIC, a Japanse electronics multinational. You will be working at the microwave department, developing the embedded controller of their latest microwave oven model, the PARA-9000 UltraWave.

1.2 Running and interacting with a simulation

Joining the embedded controller team, you learn that they are using the Statecharts language.

The team proudly shows you what they achieved so far:

OPEN MODEL

The team demonstrates that they managed to make the magnetron turn on if the START button is pressed.

The steps (in order) are:

  1. Initialize execution
  2. (un)pause (i.e., run in real-time)
  3. Press the START button

Explanation: When the START button is pressed, the input event startButton is sent to the Statechart with parameter True. (If the button is released the parameter will be False.) The Statechart has a transition from its initial state (OFF) to the ON-state with label startButton(True). This transition is enabled whenever that input event (with parameter value True) is received. The transition will fire (because there are no other enabled transitions), leaving the OFF-state and entering the ON-state. When entering the ON-state, the Statechart raises the output event setMagnetron, and the event has a parameter True.

1.4 Implementing a new feature to comply with regulations

Now that the START and STOP buttons are working, the boss calls you in his office, and briefs you about a much more serious problem: the company is in big trouble for not complying with government safety regulations.

The safety regulations mandate the magnetron to be always off whenever the microwave door is open. Unable to bribe the government inspector, they ask you to implement it.

You first verify that this is indeed a problem. Start the simulation, and start the magnetron like before, and try to open the door by clicking on it.

Yikes! This will violate the regulations for sure!

1.4.2 Implementation

Now we start implementing.

Task 3: Whenever the microwave door is open, the magnetron must be off! Implement this behavior!

Tip

This means two things:
(1) if the magnetron is on, and the door is opened, it must switch itself off.
(2) if the door is open, and the START-button is pressed, nothing can happen.

Wrong solution 1 Good: The magnetron shuts off when the door is opened.
Bad: Can still start the magnetron after opening the door!
Wrong solution 2 Good: Cannot start the magnetron after opening the door.
Bad: The magnetron doesn't shut off when the door is opened!
